# Meat in the Suit

A top-down tactical roguelike. One indestructible suit. Disposable pilots.

**Site:** https://simon-lind-glitch.github.io/meat-in-the-suit/

This repository holds the public landing page and the **issue tracker**. The game's
source is kept private.

## Reporting bugs and ideas

- In game: press **F8** to file a bug, or use the pause menu to send a suggestion.
  Both land here as issues, with the game state attached.
- Otherwise: [open an issue](../../issues/new/choose).

## Editing the site

It is plain HTML - `index.html`, `style.css`, and images/video in `media/`.
Screenshot and video blocks to copy are in a comment in the `#media` section of
`index.html`. Push to `main` and GitHub Pages republishes within a minute.
